# @agentpay/search-proxy-mcp

Web search for AI agents via DuckDuckGo

This npm package wraps the Python MCP server at [Rumblingb/search-proxy-mcp](https://github.com/Rumblingb/search-proxy-mcp).

## Install

```bash
npm install -g @agentpay/search-proxy-mcp
pip install mcp
```


## Usage

```json
{
  "mcpServers": {
    "search-proxy-mcp": {
      "command": "npx",
      "args": ["@agentpay/search-proxy-mcp"]
    }
  }
}
```
